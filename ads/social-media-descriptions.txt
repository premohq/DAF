HOW TO USE THIS FILE
==========================================================================

Each numbered section below matches a folder in /ads. Copy the caption,
then paste the hashtag block at the end (or drop it in the first comment).

Files in each folder:
  feed_4x5.jpg        Instagram / Facebook feed post (1080x1350). Use this one first.
  square_1x1.jpg      Grid posts, Facebook, Google Business Profile (1080x1080)
  story_9x16.jpg      Instagram / Facebook Stories, WhatsApp Status (1080x1920)
  reel_9x16.mp4       Reels / TikTok / YouTube Shorts: 6-second animated cut
                      (the list reel is 9 seconds). Silent, so add a trending
                      sound in the app.
  wide_16x9.jpg       X (Twitter), Facebook link posts, YouTube community (1920x1080)
  window_display_3840x2160.png
                      In-store window monitor file. Landscape file with the
                      rotated layout the current window monitors use.

Every caption below already ends with "21+ only. Please drink responsibly."
Keep that line in.

If you BOOST or run any of these as paid ads, set the audience to 21+.
Meta requires this for alcohol ads in the US.

Prices are the shelf prices from the photos. If a price changes, don't post
the old ad. Make a new one in the Forge.
